# Complete GitHub Profile Setup — Mohammad Sami

## Repository name

Create a **public** repository with this exact name:

`sami050707-ship-it`

GitHub will recognize it as your profile repository because it matches your username.

## Files to upload

Upload the contents of this package:

- `README.md`
- `ascii-portrait.svg`
- `.github/workflows/snake.yml`
- `SKILLFORGE-STACK.md`

## Result

Your profile README will show:

- ASCII portrait
- Intro/about section
- SkillForge AI featured project
- Complete verified technology stack
- Architecture diagram
- GitHub statistics
- Top languages
- Streak
- Contribution snake
- Current focus section

## Important

Do NOT upload your original personal photo to the repository unless you explicitly want it public.
The package contains only the generated ASCII SVG.

## SkillForge repository

When you create the actual project repository, a good name is:

`SkillForge-AI`

Then replace the featured-project text/link in `README.md` with:

`https://github.com/sami050707-ship-it/SkillForge-AI`

## GitHub Pages / external assets

The stats and snake sections use externally hosted SVG endpoints. The profile still works
without them, but those images may occasionally be unavailable because they are third-party services.

## No secrets

Never put your Groq API key, `.env`, passwords, or other credentials in this profile repository.
